Identidade e contactos

Altere a marca, WhatsApp (com indicativo do país), telefone, endereço, horário e Instagram.

Serviços

Cada serviço deve conter: n (nome), c (categoria), d (descrição), p (preço) e t (texto do preço).

Produtos

Cada produto deve conter: n (nome), c (categoria), d (descrição), p (preço) e img (ID de imagem Unsplash).

As alterações publicadas aparecem na loja para todos os visitantes. O acesso é protegido pelo Supabase Auth e pelas políticas da base de dados.
